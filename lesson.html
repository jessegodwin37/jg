Introduction to Web Development

Learn what web development is, how websites work and what you will learn throughout this course.

Introduction

Web development is the process of creating websites and web applications. It combines structure, design and programming to create experiences people can use through a web browser.

What You Will Learn

  • How websites work
  • HTML for website structure
  • CSS for design and layout
  • JavaScript for interaction
  • How to build real projects
  • How to publish websites

How a Website Works

When you visit a website, your browser requests files from a web server. The browser then interprets those files and displays the website.

💡 JG Tip Don't try to memorize everything at once. Learn one concept, practice it and then move to the next concept.

HTML Example

HTML provides the structure of a webpage. For example, this creates a heading: 

<h1>Welcome to JG</h1>

The browser reads the HTML and displays "Welcome to JG" as a heading.
