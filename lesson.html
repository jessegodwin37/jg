LESSON 01

Introduction to Web Development

Learn what web development is, how websites work and what you will learn throughout the JG Web Development course.

⏱️ 20 minutes 📚 Beginner 🧪 Quiz included
PART 01

What Is Web Development?

Web development is the process of creating websites and web applications that people can access through the internet.

A website can be something simple, such as a personal portfolio, or something much larger, such as an online marketplace, learning platform or social network.

💡 JG TIP

You don't need to understand everything on your first day. Learn one concept, practice it, and gradually build your skills.

PART 02

The Three Core Technologies

Modern websites commonly use three fundamental technologies.

🧱

HTML

HTML creates the structure and content of a webpage.

🎨

CSS

CSS controls the appearance, layout and visual design.

⚙️

JavaScript

JavaScript adds interaction and functionality.

PART 03

How Does a Website Work?

When you enter a website address into your browser, the browser requests the website's files from a server.

01

Browser

You enter a website address.

02

Request

The browser requests the files.

03

Server

The server sends the files.

04

Website

Your browser displays the page.

PART 04

Your First HTML Code

HTML uses elements called tags to describe the structure of webpage content. 

<h1>Welcome to JG</h1>

<p>
This is my first webpage.
</p>

The h1 element creates a main heading, while the p element creates a paragraph.

💡 Remember

HTML is about structure. CSS is about appearance. JavaScript is about behaviour and interaction.

PART 05
